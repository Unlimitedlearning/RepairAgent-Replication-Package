## 三、WSL：安装 JDK 11 并配置环境变量

```bash
sudo apt update
sudo apt install -y openjdk-11-jdk

export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export PATH=$JAVA_HOME/bin:$PATH

java -version
```

写入 `~/.bashrc`，避免重开终端失效：

```bash
echo 'export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64' >> ~/.bashrc
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

## 六、WSL：修复 CRLF 与可执行权限

先单独修 `init.sh`：

```bash
sed -i 's/\r$//' init.sh
```

再做全量 CRLF 修复：

```bash
find . -type f \( -name "*.sh" -o -name "major" -o -name "*.pl" -o -name "*.pm" \) -exec sed -i 's/\r$//' {} +
```

补可执行权限：

```bash
chmod +x init.sh
find . -type f -name "*.sh" -exec chmod +x {} +
chmod +x framework/bin/* 2>/dev/null
```

后来为了处理 `framework/bin/defects4j` 的 shebang 问题，又执行了针对文本文件的全量去 CRLF：

```bash
grep -rIl $'\r' --exclude-dir=.git . | while IFS= read -r f; do
  sed -i 's/\r$//' "$f"
done
```

并补 `framework/bin` 权限：

```bash
find framework/bin -type f -exec sed -i 's/\r$//' {} +
chmod +x framework/bin/*
```

验证 shebang：

```bash
head -1 framework/bin/defects4j | cat -A
```

正常输出末尾应为 `$`，而不是 `^M$`。
